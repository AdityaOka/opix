# OPIX

🎮 A web-based game library project built with Flutter.

## About

OPIX is a personal collection of games gathered into one library-style web app. Each game is coded by me from scratch, and this project is primarily a way to practice Flutter development and game logic, with more games planned over time.

More games coming soon.

## Tech Stack

- [Flutter](https://flutter.dev/) (Web)
- Dart

## Getting Started

1. Make sure you have [Flutter](https://docs.flutter.dev/get-started/install) installed.
2. Clone this repo:
   ```bash
   git clone https://github.com/yourusername/opix.git
   cd opix
   ```
3. Get the dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app in your browser:
   ```bash
   flutter run -d chrome
   ```
